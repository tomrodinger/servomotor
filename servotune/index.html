Immediate position target

Requires enabled closed-loop position control and an empty trajectory queue. An invalid request raises a fatal motor error; reset is required.

Alternating target test

Sends the entered angle and its negative every 250 ms, using the combined command, and starts continuous scope capture. Stop test holds the last accepted target and keeps capturing the settling response.
