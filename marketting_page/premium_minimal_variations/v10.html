IThe object

Four instruments.
One body.

A motor, a motor driver, a motion control system and an encoder, integrated in a single compact package. Nothing protrudes; nothing hangs off the back.

You issue intentions — enable MOSFETs, trapezoid move — and the motor resolves the profile itself. There is no timing-critical STEP and DIR pulse train to generate.

IIOne bus, many motors

One connection point.
Any number of axes.

Every motor speaks RS-485. Daisy-chain the whole machine and drive it all from one controller and one pair of wires.

Add a low-cost RS485 adapter and the host can be anything: Mac, PC, Raspberry Pi, Arduino, ESP32.

VIIThe protocol

Fixed, documented,
and open to read.

One bus, one baud rate, and an address scheme that never loses track of a motor.

InterfaceRS-485, any number of motors daisy-chained on one bus
Baud rateFixed at 230400
Unique addressEvery motor carries a factory-assigned 64-bit unique address, so it can always be addressed individually
AliasEach motor can also be given a 1-byte alias, 0–251, to keep packets short while still addressing it individually. 255 is the broadcast alias
Command setComprehensive coverage of motion control, configuration and status monitoring
Firmware updateSupported over the RS-485 interface
Command groupsBasic Control · Motion Control · Configuration · Status & Monitoring · Device Management

The living source of truth is motor_commands.json. Print the whole command reference locally instead, if you prefer:

$ pip3 install servomotor
$ servomotor_command -c

VIIIIndicators & buttons

Two lights, two buttons,
and no guesswork.

Green LEDFlashes slowly as a heartbeat. Flashes quickly to indicate that the bootloader is running rather than the application. Lights up briefly while a packet is being received, so it flickers with traffic on the bus
Red LEDFlashes a certain number of times to indicate fatal error codes
Reset buttonRestarts the microcontroller and returns all state to defaults
Test buttonA brief press spins the motor one way. Press for more than 0.3 s and release to spin the other way. Hold at least 2 s and release to enter closed-loop mode. Hold more than 15 s and release to run a self-calibration

The motor spins during calibration and must be able to turn freely — remove any load first.
