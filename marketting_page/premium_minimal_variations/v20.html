What it is

Four parts.One housing.

A brushless motor, a motor driver, a motion control system and an encoder — integrated into a single compact unit, nearly the same size as a NEMA 17 stepper of the same specification, with no protrusions. Available in four models — M17‑60, M17‑48, M17‑40 and M17‑34 — the series offers flexible torque and size options while keeping identical control characteristics.

One bus, many motors

Add motors.Not wiring.

Every motor sits on the same RS-485 pair. One adapter, one connection point, one piece of software — whether the machine has two axes or twenty. Each unit carries a factory-assigned 64-bit unique address, and you can give it a short 1-byte alias so packets stay small.

  • InterfaceRS-485, fixed at 230400 baud
  • Motors per busAny number, daisy-chained
  • Addressing64-bit unique address, or a 1-byte alias (0–251)
  • BroadcastAlias 255 talks to every motor at once

Typical wiring — controller, RS485 adapter, motors in a chain

High-level control

Zero step pulses.

You send commands like Enable MOSFETs and Trapezoid move. The motor generates its own motion profile from there. No timing-critical DIR/STEP pulse train, no real-time loop hogging your controller, no separate driver board to wire up.

Closed loop

32,000Corrections a second.

The built-in encoder feeds a PID control loop running at 32 kHz, so the motor knows where the shaft actually is instead of assuming. It holds position with high precision, draws far less power than a conventional stepper doing the same job, and still turns up to 560 RPM.

Developers

Two libraries.No driver code.

Python and Arduino libraries speak the protocol for you, convert your units, and expose the motor as an object. Open the port, reset, enable, move — a complete rotation fits on one screen.

spin.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.ino
#include <Servomotor.h>

Servomotor motor('X', Serial1); // alias 'X' on the RS485 UART

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);                    // let the bootloader window pass
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0);  // one rotation in one second
}

void loop() {}

Install

Python, on Mac, PC or Raspberry Pi:

$ pip3 install servomotor

Arduino, ESP32 and friends: open the Arduino IDE Library Manager and install “Servomotor”.

Five steps to first motion

  1. Connect a low-cost RS485 adapter to your Mac, PC, Raspberry Pi, Arduino or ESP32.
  2. Plug in the included cable and supply 12–24 V.
  3. Install the library — pip3 install servomotor or “Servomotor”.
  4. Give the motor a 1-byte alias (0–251) so your packets stay short.
  5. Call enable_mosfets(), then trapezoid_move(), and watch the shaft turn.

Unit system

Your units.Its maths.

The motors work in integer internal units so the motion maths stays fast. The Python and Arduino libraries convert automatically in both directions, so you write degrees, seconds, amps or fahrenheit — whatever suits the job — and never touch a scaling factor.

Indicators & controls

Two LEDs.Two buttons.

Everything you need to know about a motor is visible from the back of it — and you can spin it, reset it or calibrate it without writing a line of code.

  • Green LEDFlashes slowly as a heartbeat; flashes quickly when the bootloader is running rather than the application; and lights up briefly while a packet is being received, so it flickers with traffic on the bus.
  • Red LEDIndicates fatal error codes by flashing a certain number of times.
  • Reset buttonRestarts the microcontroller and returns all state to defaults.
  • Test buttonA brief press spins one way. Press for more than 0.3 s and release to spin the other way. Hold at least 2 s and release to enter closed-loop mode. Hold more than 15 s and release to run a self-calibration.

The motor spins during calibration and must be able to turn freely — remove any load first.
