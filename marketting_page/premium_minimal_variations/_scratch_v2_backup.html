What it is

Four components that normally live in four places, assembled into a single housing at the factory.

Made as one part,
not four.

A conventional axis is a shopping list: a stepper, a driver board, a controller to time the pulses, an encoder if you want to know where you actually are, and the wiring that ties the four together. The M17 Series is that list, made once, properly, in a package barely larger than the stepper it replaces.

Four models — M17-60, M17-48, M17-40 and M17-34 — give you a choice of torque and length while keeping identical control characteristics, so a machine can mix sizes without changing a line of code.

The motor

Brushless, NEMA 17 footprint, 42.2 × 42.2 mm, with the same torque-to-weight ratio as an equivalent stepper.

Integrated power stage with over-current, over-voltage and over-temperature protection built in.

The controller

Motion profiling on board. You send “Trapezoid move”; the motor works out the rest.

The encoder

Closed-loop feedback into a PID loop running at 32 kHz, with self-calibration and error handling.

One bus

RS-485, daisy-chained, from a single connection point on your computer.

Two wires.
Any number of motors.

Motors chain from one to the next. Add an axis by adding a motor to the end of the chain — the controller, the adapter and the code all stay where they are.

  • InterfaceRS-485, a single two-wire differential pair shared by every motor.
  • Bus capacityAny number of motors on a single daisy chain, controlled from one connection point.
  • HostMac, PC, Raspberry Pi, Arduino or ESP32 — with a low-cost RS485 adapter.
  • PowerA shared 12–24 V supply feeds the chain.
  • Baud rate230400, fixed — the same for every motor on the chain.

Getting started

Two libraries, one command set. Install, address a motor, move it.

A few lines in Python.
A few more in Arduino.

The libraries speak in whatever units you think in and hand the motor the integers it wants. Nothing to configure, nothing to time.

Swipe a listing sideways to read it →

spin.py — Python
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.ino — Arduino
#include <Servomotor.h>

Servomotor motor('X', Serial1); // alias 'X', RS485 UART

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);   // let the bootloader window pass
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0); // one rotation, one second
}

void loop() {}

The short version

Five steps from a box on the bench to a shaft that turns.

  1. Connect a low-cost RS485 adapter to your Mac, PC, Raspberry Pi, Arduino or ESP32.
  2. Daisy-chain the motors on the RS-485 pair and feed the chain from a 12–24 V supply.
  3. Install the library — pip3 install servomotor, or add “Servomotor” from the Arduino Library Manager.
  4. Address each motor by its factory 64-bit unique address, or give it a short 1-byte alias.
  5. Send Enable MOSFETs, then Trapezoid move, and watch it turn.

Communication

A small, well-documented protocol on ordinary RS-485 hardware.

Every motor answers
to its own name.

Each unit leaves the factory with a unique address it will always answer to. Give it a short alias as well, and your packets stay small.

Physical layer
RS-485, any number of motors daisy-chained on one bus.
Baud rate
230400, fixed.
Unique address
64-bit, assigned at the factory. Always addressable individually.
Alias
One byte, 0–251, to keep packets short while still addressing a single motor. 255 is the broadcast alias.
Firmware update
Supported over the same RS-485 interface — no cable to swap, no motor to unmount.

On the back

Two LEDs and two buttons. Everything the motor needs to tell you, without a screen.

It says what it’s doing
before you ask.

Green LED
Flashes slowly as a heartbeat, and quickly to say the bootloader is running rather than the application. It also lights briefly while a packet is being received, so it flickers with traffic on the bus.
Red LED
Flashes a certain number of times to indicate fatal error codes.
Reset
Restarts the microcontroller and returns all state to defaults.
Test
Spins the motor without a host. A brief press spins one way; press for more than 0.3 s and release to spin the other way; hold at least 2 s and release to enter closed-loop mode; hold more than 15 s and release to run a self-calibration.

The motor spins during calibration and must be able to turn freely — remove any load first.
