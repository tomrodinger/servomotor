What it is

4

Devices in one housing

Motor. Driver. Motion controller. Encoder. Bought once, wired once, powered once.

Four devices.
One part number.

The M17 Series integrates a motor, a motor driver, a motion controller and an encoder into a single compact package — nearly the same size as a NEMA 17 stepper of the same specification, with no protrusions.

You send high-level commands like “Enable MOSFETs” and “Trapezoid move” over RS-485. There is no timing-critical DIR/STEP pulse generation to write, no driver board to source, no encoder to align.

Available in four models — M17-60, M17-48, M17-40 and M17-34 — the series covers a spread of torque and size while keeping identical control characteristics, so a design that works on one works on all four.

One bus, many motors

230400baud

RS-485, fixed

One pair of wires, one connection point, and every motor in the machine answers on it.

One connection.
Any number of axes.

Every M17 speaks RS-485, so motors daisy-chain along a single bus and are controlled from a single connection point — a Raspberry Pi, an Arduino, an ESP32, a Mac or a PC with a low-cost RS485 adapter.

Each motor carries a factory-assigned 64-bit unique address, and can also be given a short 1-byte alias so packets stay small. Address one motor, or address them all at once.

Getting started

2

Official libraries

Python and Arduino. Same commands, same units, same motor.

Two libraries.
One command set.

Reset, enable the MOSFETs, send a trapezoid move — the program is that short in both languages. Install one, plug in an RS485 adapter, and the motor turns.

spin.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s

pip3 install servomotor

spin.ino 
#include <Servomotor.h>

Servomotor motor('X', Serial1);  // alias 'X', RS485 UART

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);                   // let the bootloader pass
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0); // one rotation, one second
}

void loop() {}

Arduino IDE Library Manager: Servomotor

Five steps to a spinning shaft

  1. Get a low-cost RS485 adapter — Gearotons sells a 3-in-1 — and connect it to your Raspberry Pi, Arduino, ESP32, Mac or PC.
  2. Plug in the cable that came with the motor and give it 12–24 V.
  3. Install a library: pip3 install servomotor, or “Servomotor” from the Arduino Library Manager.
  4. Reset the motor, enable the MOSFETs, and send a trapezoid move.
  5. Print the full command reference any time with servomotor_command -c.

Communication protocol

64bit

Unique address, per motor

Assigned at the factory. Nothing to configure, nothing to collide.

A protocol you can
read in an afternoon.

RS-485 at a fixed 230400 baud, any number of motors on one bus. A comprehensive command set covers motion control, configuration and status monitoring — and firmware updates travel over the same two wires, so a machine in the field never needs opening.

Address a motor by its 64-bit unique address, or give it a 1-byte alias from 0 to 251 to keep packets short. Alias 255 broadcasts to everything on the bus.

Indicators & controls

Two LEDs.
Two buttons.

Everything you need to know about a motor is on its back panel — before you have written a line of code.

  • Green LEDFlashes slowly as a heartbeat, and quickly when the bootloader is running rather than the application. It also lights up briefly while a packet is being received, so it flickers with traffic on the bus.
  • Red LEDFlashes a certain number of times to indicate fatal error codes.
  • ResetRestarts the microcontroller and returns all state to defaults.
  • TestSpins the motor without a host. A brief press spins one way.

The test button, by the second

0.3s

Press & release

Longer than 0.3 s spins the other way.

2s

Hold & release

At least 2 s enters closed-loop mode.

15s

Hold & release

More than 15 s runs a self-calibration.

The motor spins during calibration and must be able to turn freely, so remove any load first.
