01 —

Nothing bolted on.
Nothing left out.

A stepper needs a driver board, a controller and an encoder bolted around it. The M17 has all of it inside the housing, nearly the size of a NEMA 17 stepper of the same specification, with no protrusions.

Available in four models — M17‑60, M17‑48, M17‑40 and M17‑34 — the series offers flexible options to match specific torque and size requirements, while the control characteristics stay identical across the range.

06 —

Import the library.
Turn the shaft.

Two libraries, one command set. Both convert your units to the motor’s internal integers, so no code below is doing arithmetic you did not ask for.

spin.pyPython
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s

pip3 install servomotor

spin.inoArduino C++
#include <Servomotor.h>

Servomotor motor('X', Serial1);  // alias 'X', RS485

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);        // bootloader window
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0);  // 1 rotation, 1 s
}

void loop() {}

07 —

You write degrees.
It counts integers.

The motors use integer internal units so the motion maths stays fast. The Python and Arduino libraries convert automatically, in both directions, for all seven quantities.

08 —

Addressed twice.
Never ambiguous.

Every motor leaves the factory with a 64‑bit unique address. Give it a one‑byte alias as well and the packets get shorter without losing individual addressing.

Two LEDs.

The back panel tells you what the motor is doing before you open a terminal — and drives it without one.

Fig. 09 — Rear panel

Status LEDs

Green, slow
Heartbeat — the application is running
Green, fast
The bootloader is running, not the application
Green, brief
Lights while a packet is being received — it flickers with traffic on the bus
Red, counted
Flashes a set number of times to indicate a fatal error code

Buttons: Reset and Test

Reset
Restarts the microcontroller and returns all state to defaults
Test, brief
Spins the motor one way
Test, > 0.3 s
Release to spin the other way
Test, ≥ 2 s
Release to enter closed‑loop mode
Test, > 15 s
Release to run a self‑calibration

Remove the load first. The motor spins during calibration and must be able to turn freely.
