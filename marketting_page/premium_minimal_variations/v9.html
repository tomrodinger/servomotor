What’s inside

Four things you used to buy separately.
One thing you bolt on.

There is no driver board to mount, no controller to feed with step pulses, and no encoder to align. Everything arrives assembled inside the motor, ready to talk.

The motor

A brushless servo in a body nearly the same size as the stepper it replaces — and with no protrusions to design around.

The driver

Power electronics on board, with over-current, over-voltage and over-temperature protection watching your back.

The motion controller

Trapezoid profiles, multiple operation modes and self-calibration run inside the motor, so your code stays simple.

The encoder

Closed-loop position feedback with a PID loop running at 32 kHz — precise, and far more power efficient than a stepper.

Available in four models — M17-60, M17-48, M17-40 and M17-34 — the series gives you flexible options to match the torque and the size your application needs, while keeping identical control characteristics. Learn one, and you have learned all four.

One bus, many motors

Connect once.
Then keep adding axes.

Every M17 speaks RS-485, so you daisy-chain them and drive the whole machine from a single connection point. Whether you have two motors or twenty, your controller sees one bus.

  • One adapter is all you need. A low-cost RS485 adapter connects your Mac, PC, Raspberry Pi, Arduino or ESP32 to the chain.
  • Any number of motors. Add another axis by adding another motor to the same pair of wires.
  • One shared supply. Anything from 12 to 24 V powers the whole chain.

A complete bench setup: computer, RS485 adapter, motors in a chain, one power supply.

Getting started

Install a library.
Move something.

Two libraries, one idea: you describe the movement you want in the units you think in, and the motor does the profiling. Here is a full first program in each language.

spin.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.ino
#include <Servomotor.h>

// alias 'X' on the RS485 UART
Servomotor motor('X', Serial1);

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);  // let the bootloader window pass
  motor.enableMosfets();
  // one rotation in one second
  motor.trapezoidMove(1.0, 1.0);
}

void loop() {}

Communication protocol

A bus you can reason about.
And update over.

Nothing here is hidden from you. The protocol is documented, the command list is a file you can read, and new firmware travels down the same two wires as everything else.

How addressing works

  • 230400 baud, fixed. One setting, nothing to negotiate.
  • A 64-bit unique address is assigned to every motor at the factory, so you can always reach one specific unit.
  • A 1-byte alias (0–251) can be given to each motor to keep packets short while still addressing it individually. 255 is the broadcast alias.
  • Any number of motors can share one daisy-chained bus.
  • Firmware updates travel over RS-485 — no disassembly, no programmer.

Indicators and controls

Two LEDs and two buttons
keep you informed.

Everything you need for a quick sanity check is on the back of the motor — no software, no oscilloscope, no guessing.

  • Green LED. Flashes slowly as a heartbeat, and quickly to tell you the bootloader is running rather than the application. It also lights up briefly while a packet is being received, so it flickers with traffic on the bus.

  • Red LED. Indicates fatal error codes by flashing a certain number of times.

  • Reset

    Restarts the microcontroller and returns all state to defaults.

  • Test

    Spins the motor without a computer. A brief press spins one way; press for more than 0.3 s and release to spin the other way; hold at least 2 s and release to enter closed-loop mode; hold more than 15 s and release to run a self-calibration.

The motor spins during calibration and must be able to turn freely — remove any load first.
