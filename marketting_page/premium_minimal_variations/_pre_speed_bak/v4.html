What it is

Four systems.
One housing.

A conventional axis is an assembly — a stepper, a driver board, a controller, an encoder, and the wiring that has to keep all four honest. The M17 arrives as one part, already agreed with itself.

01 Motor A compact body, near enough the same size as a NEMA 17 stepper of the same specification, with no protrusions — and the same torque-to-weight ratio.
02 Driver On board. No external electronics to specify, mount, cool or wire. Over-current, over-voltage and over-temperature protection are built in.
03 Motion controller Trapezoid movement profiles, multiple operation modes, self-calibration and comprehensive error handling — all computed inside the motor.
04 Encoder Position is measured, not assumed. Closed-loop control runs on a PID loop at 32 kHz, and draws less power doing it than a conventional stepper.

Getting started

Install. Import.
Move.

The libraries carry the arithmetic. You write the intent — a unit, a distance, a duration — and the motor turns it into a profile.

spin.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.ino 
#include <Servomotor.h>

// alias 'X' on the RS485 UART
Servomotor motor('X', Serial1);

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);   // let the bootloader window pass
  motor.enableMosfets();

  // one rotation in one second
  motor.trapezoidMove(1.0, 1.0);
}

void loop() {}

Unit system

It thinks in integers.
You never have to.

Internally the motors use integer units so the motion maths stays fast. The Python and Arduino libraries convert on the way in and on the way out — so you work in whatever unit the drawing is dimensioned in.

Communication protocol

A short packet.
A long reach.

One robust serial protocol carries motion, configuration, status and maintenance — and it never changes shape as the machine grows.

InterfaceRS-485, two wires, daisy-chained to any number of motors.
Baud rateFixed at 230400.
Unique addressEvery motor carries a factory-assigned 64-bit unique address, so it can always be reached individually.
AliasEach motor can also be given a 1-byte alias (0–251), keeping packets short while still addressing it individually.
BroadcastAlias 255 speaks to the whole bus at once.
Firmware updateSupported over the RS-485 interface — the motor stays where it is.
Command groupsBasic Control · Motion Control · Configuration · Status & Monitoring · Device Management.

On the back

Two lights.
Two buttons.

Everything the motor wants to tell you, it tells you before you open a terminal.

Status LEDs

Green flashes slowly as a heartbeat, and quickly to indicate that the bootloader is running rather than the application. It also lights up briefly while a packet is being received — so it flickers with the traffic on the bus.

Red flashes a certain number of times to indicate fatal error codes.

Reset

Restarts the microcontroller and returns all state to defaults.

Test

Spins the motor without a host. A brief press spins one way; press for more than 0.3 s and release to spin the other way; hold at least 2 s and release to enter closed-loop mode; hold more than 15 s and release to run a self-calibration.

The motor spins during calibration and must be able to turn freely — remove any load first.
