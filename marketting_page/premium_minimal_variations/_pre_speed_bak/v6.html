§ 01

What it is

Four subsystems.
One part number.

The usual build is a stepper, a driver board, a pulse generator and — if you can afford the space — an encoder, joined by a loom you have to debug. The M17 puts all four inside the frame, with no protrusions, in a package nearly the same size as a stepper of the same specification.

01 / Motor

Standard frame

42.2 × 42.2 mm body on standard NEMA 17 mounting dimensions, with the same torque-to-weight ratio as an equivalent stepper motor.

02 / Driver

Power stage inside

The driver lives on board, with integrated over-current, over-voltage and over-temperature protection. Feed it anywhere from 12 to 24 V.

03 / Controller

Motion, not pulses

Trapezoid movement profiles, multiple operation modes, self-calibration and comprehensive error handling execute on the motor itself.

04 / Encoder

The loop is closed

A built-in encoder feeds a PID loop running at 32 kHz. Closed-loop control is much more power efficient than a conventional stepper.

§ 02

One bus

One twisted pair.
Every axis on it.

Motors daisy-chain on a single RS-485 interface, so any number of axes reaches the host through one connection point. Each motor answers to its own address; adding the next one adds two wires, not another driver, another cable run and another port.

§ 06

Getting started

Install the library.
Move the motor.

Two libraries, one API shape. Open the port, pick your units, reset, enable the MOSFETs, command a move. Everything below is the whole program — there is no framework underneath it.

spin.pyPython
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.inoArduino
#include <Servomotor.h>

Servomotor motor('X', Serial1); // alias 'X' on the RS485 UART

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);                    // let the bootloader window pass
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0);   // one rotation in one second
}

void loop() {}
Install  pip3 install servomotor

Unit system

Integer units inside.
Your units outside.

The motor works in integer internal units so the motion maths stays fast and deterministic. The Python and Arduino libraries convert on the way in and on the way out, so you write degrees, seconds and amps — or encoder counts and timesteps, if that is how you think.

§ 08

Communication protocol

A documented bus,
not a black box.

RS-485 at a fixed 230400 baud. Every motor leaves the factory with a 64-bit unique address, so it can always be reached individually — even before you have configured anything. Give it a short alias afterwards to keep packets small.

InterfaceRS-485
Baud rate230400, fixed
TopologyDaisy chain, any number
Unique address64-bit, factory assigned
Alias1 byte, 0–251
Broadcast alias255
Firmware updateOver the same bus

§ 09

LEDs & buttons

Two LEDs, two buttons.
The state of the motor, on the motor.

You can read what a motor is doing from across the bench, and you can make it move without writing a line of code — useful when you are commissioning a machine with a screwdriver in the other hand.

Green LED

Flashes slowly as a heartbeat: the application is running. Flashes quickly when the bootloader is running instead of the application. Lights briefly while a packet is being received, so it flickers with traffic on the bus.

Red LED

Flashes a certain number of times to indicate a fatal error code.

Reset

Restarts the microcontroller and returns all state to defaults.

Test

Spins the motor with no host attached. A brief press spins one way. Press for more than 0.3 s and release to spin the other way. Hold at least 2 s and release to enter closed-loop mode. Hold more than 15 s and release to run a self-calibration.

Caution — the motor spins during calibration and must be able to turn freely. Remove any load first.
