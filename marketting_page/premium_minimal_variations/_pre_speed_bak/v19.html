01What it is

Stop assembling motion.
Start commanding it.

Four parts that normally arrive in four boxes, wired by hand and tuned by trial. The M17 ships them as one compact unit, nearly the same size as the NEMA 17 stepper it replaces — and with no protrusions to design around.

02One bus, many motors

Chain them.
Address every one.

One RS-485 pair leaves your controller and every axis hangs off it. Add a motor, add an address — the wiring never changes shape.

  • —Daisy-chain any number of motors and drive them all from a single connection point.
  • —Every unit carries a factory-assigned 64-bit unique address, so it can always be reached individually.
  • —Give it a short 1-byte alias (0–251) for compact packets — or talk to the whole bus with the broadcast alias 255.
  • —All it takes on the host side is a low-cost RS485 adapter and 12–24 V of power.

06Getting started

Install. Connect.
Turn one revolution.

Two libraries, one idea: write the motion you mean, in the units you think in. The library handles the packets, the conversions and the bus.

spin.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.ino
#include <Servomotor.h>

Servomotor motor('X', Serial1); // alias 'X' on the RS485 UART

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);                    // let the bootloader window pass
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0);  // one rotation in one second
}

void loop() {}

  1. STEP 01

    Get an adapter

    Any low-cost RS485 adapter will do; Gearotons sells a 3-in-1. A cable comes with the motor.

  2. STEP 02

    Wire the bus

    RS485 A and B to the chain, 12–24 V to the motors. Share a ground — optional, strongly recommended.

  3. STEP 03

    Install a library

    pip3 install servomotor, or add Servomotor from the Arduino Library Manager.

  4. STEP 04

    Find and name

    Detect what is on the bus, then hand each motor a 1-byte alias so your code stays readable.

  5. STEP 05

    Make it move

    Reset, enable the MOSFETs, call a trapezoid move — and watch the shaft land on the degree.

08Communication protocol

One pair of wires.
A whole command set.

RS-485, fixed and predictable. Everything the motor can do is reachable over the same two wires — including its own firmware.

09Indicators & buttons

Glance at it.
Read its state.

Green — heartbeat & bus traffic Red — fatal errors
Green LED
Flashes slowly as a heartbeat, and quickly when the bootloader is running rather than the application. It also lights briefly while a packet is being received, so it flickers with traffic on the bus.
Red LED
Flashes a certain number of times to indicate fatal error codes.
Reset button
Restarts the microcontroller and returns all state to defaults.
Test button
Brief press spins one way. Press > 0.3 s and release to spin the other way. Hold ≥ 2 s and release for closed-loop mode. Hold > 15 s and release to run a self-calibration.

The motor spins during calibration and must be able to turn freely — remove any load first.
