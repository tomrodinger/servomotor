01Integration

A stepper’s footprint.
A servo’s composure.

An M17 is not a motor with electronics bolted to it. Four things that usually live on four different parts of a machine were designed together and sealed into one body, very nearly the size of the NEMA 17 stepper it replaces, with nothing protruding.

The motorA brushless machine in the standard 42.2 × 42.2 mm frame, with the same torque-to-weight ratio as an equivalent stepper.
The driverIntegrated power stage with over-current, over-voltage and over-temperature protection.
The controllerMotion profiling on board. You ask for a trapezoid move; the motor works out the ramp.
The encoderBuilt in, closing a PID loop at 32 kHz — and drawing considerably less power than a stepper doing the same work.

Self-calibration, multiple operation modes, comprehensive error handling and status monitoring through indicator LEDs are part of the same package. Four models — M17-60, M17-48, M17-40 and M17-34 — cover the torque range while behaving identically under the same commands.

02One bus

One pair of wires.
Every axis on it.

The M17 speaks RS-485. Daisy-chain as many motors as the machine needs and reach all of them from a single connection point — a Raspberry Pi, an Arduino, an ESP32, a Mac or a PC, with nothing more exotic than a low-cost RS485 adapter.

A computer, a USB RS485 adapter and a 12–24 V supply. Green is A, blue is B; a ground connection between adapter and motors is optional but highly recommended.

06Developers

A few lines,
then it turns.

Two libraries, one behaviour. Open the port, name the motor, ask for a move. Everything timing-critical happens inside the housing.

Pythonspin.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
Arduinospin.ino
#include <Servomotor.h>

// alias 'X' on the RS485 UART
Servomotor motor('X', Serial1);

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);  // let the bootloader window pass
  motor.enableMosfets();
  // one rotation in one second
  motor.trapezoidMove(1.0, 1.0);
}

void loop() {}
pip3 install servomotor Arduino IDE Library Manager: “Servomotor”

Getting started, in five steps

  1. Install the library. pip3 install servomotor, or add “Servomotor” from the Arduino Library Manager.
  2. Wire the bus. Connect the RS485 adapter — green to A, blue to B — and share a ground with the motors.
  3. Power the chain. Anything from 12 to 24 volts, across every motor on the bus.
  4. Name each motor. Give it a one-byte alias, or address it by its factory-assigned 64-bit unique address.
  5. Move. Enable the MOSFETs and send a trapezoid move.

08Protocol

A protocol you can
read in an afternoon.

RS-485, one fixed baud rate, two ways to address a motor, and a command set documented in a file you can open. Firmware updates travel down the same two wires as the motion commands.

InterfaceRS-485, baud rate fixed at 230400. Any number of motors daisy-chained on one bus.
Unique addressEvery motor carries a factory-assigned 64-bit unique address, so it can always be reached individually.
AliasEach motor can also be given a 1-byte alias, 0 to 251, to keep packets short while still addressing it individually. 255 is the broadcast alias.
FirmwareFirmware update over the RS-485 interface is supported — no disassembly, no separate programmer.
Command setA comprehensive set covering motion control, configuration and status monitoring.
Basic control Motion control Configuration Status & monitoring Device management

09On the motor

Two lights.
Two buttons.

The rear face carries the spec label, the QR codes, and everything you need to check on a motor or exercise it without a computer attached.

Green LEDFlashes slowly as a heartbeat, and quickly when the bootloader is running rather than the application. It also lights up briefly while a packet is being received, so it flickers with traffic on the bus.
Red LEDFlashes a certain number of times to indicate fatal error codes.
Reset buttonRestarts the microcontroller and returns all state to defaults.
Test buttonSpins the motor without a controller. A brief press spins one way. Press for more than 0.3 s and release to spin the other way. Hold at least 2 s and release to enter closed-loop mode. Hold more than 15 s and release to run a self-calibration.

Before self-calibrationThe motor spins during calibration and must be able to turn freely. Remove any load first.
