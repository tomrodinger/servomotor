Getting started

Install a library.
Turn a shaft.

Python and Arduino libraries speak the protocol for you. A handful of lines is a working move — in either language.

spin.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.ino 
#include <Servomotor.h>

// alias 'X' on the RS485 UART
Servomotor motor('X', Serial1);

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);   // let the bootloader window pass
  motor.enableMosfets();
  // one rotation in one second
  motor.trapezoidMove(1.0, 1.0);
}

void loop() {}

pip3 install servomotor Arduino IDE Library Manager: “Servomotor”

  1. Connect an adapter. A low-cost RS485 adapter links your Mac, PC, Raspberry Pi, Arduino or ESP32 to the bus. Gearotons sells a 3-in-1 RS485 adapter.
  2. Power and chain. Give the motors 12–24 V and daisy-chain them on one RS-485 bus. A cable comes with the motor.
  3. Install a library. pip3 install servomotor for Python, or add “Servomotor” from the Arduino Library Manager.
  4. Address your motors. Use the factory-assigned 64-bit unique address, or give each motor a short 1-byte alias between 0 and 251.
  5. Enable and move. Enable the MOSFETs, then send a trapezoid move and watch the shaft turn.

Communication protocol

A protocol you can hold
in your head.

RS-485, one fixed baud rate, and a command set organised the way you already think about a machine.

The essentials

InterfaceRS-485, baud rate fixed at 230400
TopologyAny number of motors daisy-chained on one bus
Unique addressEvery motor carries a factory-assigned 64-bit unique address, so it can always be addressed individually
AliasA 1-byte alias, 0–251, keeps packets short while still addressing one motor. 255 is the broadcast alias
MaintenanceFirmware update over the RS-485 interface is supported

On the back

Two LEDs.
Two buttons.

Everything you need to know about a motor, without connecting to it — and everything you need to make it move, without writing a line.

  • Green LEDFlashes slowly as a heartbeat, and quickly to indicate the bootloader is running rather than the application. It also lights up briefly while a packet is being received, so it flickers with communication on the bus.
  • Red LEDIndicates fatal error codes by flashing a certain number of times.
  • Reset buttonRestarts the microcontroller and returns all state to defaults.
  • Test buttonA brief press spins the motor one way. Press for more than 0.3 s and release to spin the other way. Hold at least 2 s and release to enter closed-loop mode. Hold more than 15 s and release to run a self-calibration.

The motor spins during calibration and must be able to turn freely, so remove any load first.
