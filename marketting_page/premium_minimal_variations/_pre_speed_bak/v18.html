M17 Series / The Case for Integration § 01

A stepper is only
half a machine.

Before a stepper motor turns a single degree it needs company: a driver board to push current through the coils, a controller to generate the pulse train, wiring to join the two, and — if you would like to know where the shaft actually ended up — an encoder mounted wherever it happens to fit. Four parts, four things to specify, four things to fail, and a control cabinet that grows every time the machine gains an axis.

The M17 Series begins from the other end of the problem. Motor, motor driver, motion controller and encoder are integrated into a single compact package that is nearly the same size as a NEMA 17 stepper of the same specification, with no protrusions to design around. The mounting dimensions are the standard NEMA 17 pattern. The supply is anything between 12 and 24 volts. What used to be a shelf of electronics is now the thing already bolted to the bracket.

You stop generating pulses
and start issuing instructions.

The difference shows up first in the code. Rather than timing-critical DIR and STEP pulse generation, the M17 accepts high-level commands — Enable MOSFETs, Trapezoid move — and works out the profile itself. The host is no longer a real-time metronome; it is simply the thing that decides what should happen next. A Raspberry Pi, an Arduino, an ESP32, a Mac or a PC can all take the job, and all any of them needs is a low-cost RS485 adapter.

Underneath, a built-in encoder feeds a PID control loop running at 32 kHz. Position is verified rather than assumed, and closed-loop operation turns out to be much more power efficient than a conventional stepper — while the torque-to-weight ratio stays the same as an equivalent stepper motor. Over-current, over-voltage and over-temperature protection are integrated, alongside comprehensive error handling, self-calibration, multiple operation modes and status monitoring through the indicator LEDs.

Four models cover the torque range: the M17-60, the M17-48, the M17-40 and the M17-34. All four share one 42.2 × 42.2 mm footprint, one 20.6 mm shaft, one maximum speed of 560 RPM, and identical control characteristics — so the choice is about torque and size, never about relearning the machine. This is precise motion for robotics, CNC, automated test equipment and scientific instruments, sold as one part number instead of four.

M17 Series / One Bus, Many Motors § 02

One pair of wires.
Any number of axes.

Every M17 speaks RS-485, so motors are daisy-chained along a single bus and driven from a single connection point. Add the tenth axis the way you added the second: one more motor on the chain, one more address in your program.

Each unit carries a factory-assigned 64-bit unique address, and can also be given a short one-byte alias so that everyday packets stay small. There is no cabinet of drivers to expand, and no per-axis controller card to buy.

M17 Series / The Workshop § 05

Eight lines of Python.
One rotation of the shaft.

Install the library, name the motor, tell it what to do. The same story in C++ if the host is an Arduino.

spin.pyPython
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.inoArduino
#include <Servomotor.h>

Servomotor motor('X', Serial1);  // alias 'X' on the RS485 UART

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);                   // let the bootloader window pass
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0); // one rotation in one second
}

void loop() {}

M17 Series / The Unit System § 06

Work in your units.
We do the maths.

Internally the motors use integer units so the motion arithmetic stays fast. The Python and Arduino libraries convert on the way in and on the way out, so degrees, radians, RPM or raw encoder counts are all equally valid ways to say the same thing.

M17 Series / Protocol § 07

A bus you can
read end to end.

Nothing about the M17 protocol is hidden. The command set is documented, machine-readable, and printable from your own terminal.

Physical layer
RS-485, with the baud rate fixed at 230400.
Topology
Any number of motors daisy-chained on one bus, driven from a single connection point.
Unique address
Every motor carries a factory-assigned 64-bit unique address, so it can always be addressed individually — even before it has been configured.
Alias
Each motor can also be given a 1-byte alias (0–251) to keep packets short while still addressing it individually. 255 is the broadcast alias.
Command groups
Basic Control  ·  Motion Control  ·  Configuration  ·  Status & Monitoring  ·  Device Management. A comprehensive set covering motion control, configuration and status monitoring.
Firmware update
Supported over the same RS-485 interface — no programmer, no disassembly, no removing the motor from the machine.
Source of truth
The living command reference is motor_commands.json — read it on GitHub.
# print the whole command reference locally $ pip3 install servomotor # once $ servomotor_command -c
M17 Series / Indicators & Controls § 08

Two LEDs,
two buttons, no screen.

Everything you need to know at a glance, and everything you need to do without a host attached.

Green — heartbeat and traffic

Flashes slowly as a heartbeat, and quickly to indicate that the bootloader is running rather than the application. It also lights briefly while a packet is being received, so it flickers with the traffic on the bus.

Red — faults

Flashes a certain number of times to indicate fatal error codes.

Reset

Restarts the microcontroller and returns all state to defaults.

Test

Spins the motor. A brief press spins one way; press for more than 0.3 s and release to spin the other way; hold at least 2 s and release to enter closed-loop mode; hold more than 15 s and release to run a self-calibration.

The motor spins during calibration and must be able to turn freely, so remove any load first.
