01 — Integration

Everything an axis needs.Nothing on the outside.

The M17 Series is an all-in-one motion control solution: motor, motor driver, motion controller and encoder in a single compact package with no protrusions — nearly the same size as a NEMA 17 stepper of the same specification.

A driver board, a controller, a feedback device and the loom between them collapse into one part number, one mounting operation, one pair of signal wires. Available in four models — M17‑60, M17‑48, M17‑40 and M17‑34 — so torque and stack height can be matched to the axis while the control characteristics stay identical.

01

Motor

Standard NEMA 17 mounting dimensions, 42.2 × 42.2 mm face, 5 mm shaft. Torque-to-weight ratio matches an equivalent stepper.

02

Driver

Integrated power stage running from 12 to 24 V, with over-current, over-voltage and over-temperature protection built in.

03

Motion controller

Executes trapezoid movement profiles from high-level commands. No timing-critical STEP/DIR pulse train to generate on the host.

04

Encoder

Built-in position feedback closing a PID loop at 32 kHz — and, in closed loop, drawing far less power than a conventional stepper.

02 — RS-485 bus

Two wires out.Every axis on the bus.

Motors daisy-chain on a single RS-485 bus and answer from one connection point. Add the ninth axis the way you added the first: another motor on the same pair.

The host can be a Mac, a PC, a Raspberry Pi, an Arduino or an ESP32. The only extra hardware is a low-cost RS485 adapter.

06 — Developers

Unpack, install,command the first move.

Two open-source libraries — Python and Arduino C++ — both speaking the same protocol and both converting units at the boundary. A handful of lines is enough to turn a shaft one full revolution.

spin.pyPython
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.inoArduino
#include <Servomotor.h>

Servomotor motor('X', Serial1);   // alias 'X' on RS485

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);          // let the bootloader window pass
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0); // one rotation in 1 s
}

void loop() {}

09 — Indicators & controls

Status on the housing.No terminal required.

Two status LEDs and two buttons on the rear face. Enough to confirm a motor is alive, moving and answering — with nothing connected but power.

Green LED — heartbeat and traffic

Flashes slowly as a heartbeat. A fast flash means the bootloader is running rather than the application. It also lights up briefly while a packet is being received, so it flickers with communication on the bus.

Red LED — faults

Indicates fatal error codes by flashing a certain number of times.

Reset button

Restarts the microcontroller and returns all state to defaults.

Test button

Spins the motor without a host. A brief press spins one way. Press for more than 0.3 s and release to spin the other way. Hold at least 2 s and release to enter closed-loop mode. Hold more than 15 s and release to run a self-calibration.

Before self-calibration: the motor spins during calibration and must be able to turn freely. Remove any load first.
