What it is

Four systems go in.
One package comes out.

The M17 Series integrates the motor, the motor driver, the motion controller and the encoder into a single compact body — and talks to your machine over RS‑485.

01

Motor

A brushless servo in a NEMA 17 body, with the torque-to-weight ratio of an equivalent stepper.

02

Driver

Power electronics live inside the housing. No external driver board, no wiring harness between them.

03

Motion controller

Trapezoid profiles, multiple operation modes, self-calibration and comprehensive error handling, on board.

04

Encoder

Position feedback closes the loop at 32 kHz, so the motor knows where it is and holds it there.

The series comes in four models — M17‑60, M17‑48, M17‑40 and M17‑34 — so you can match torque and size to each axis while the control characteristics stay identical. Learn one, and you know them all.

Getting started

Install a library.
Move a motor.

Two languages, the same commands. The libraries handle packets, units and error codes, so your first program is a few lines long.

spin.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
spin.ino 
#include <Servomotor.h>

// alias 'X' on the RS485 UART
Servomotor motor('X', Serial1);

void setup() {
  motor.setPositionUnit(PositionUnit::SHAFT_ROTATIONS);
  motor.setTimeUnit(TimeUnit::SECONDS);

  motor.systemReset();
  delay(1500);  // let the bootloader pass
  motor.enableMosfets();
  motor.trapezoidMove(1.0, 1.0);  // 1 turn in 1 s
}

void loop() {}

pip3 install servomotor Arduino IDE Library Manager: “Servomotor”

Your first five minutes

  1. Install the library for your language — pip3 install servomotor, or “Servomotor” in the Arduino Library Manager.
  2. Wire the bus. Connect the motor to your computer or board through a low-cost RS485 adapter, using the included cable.
  3. Power it from anywhere in the 12–24 V range.
  4. Give it an alias — a single byte, 0–251 — or address it by its factory-assigned 64-bit unique address.
  5. Run your first move. Enable the MOSFETs, then send a trapezoid move and watch the shaft turn.

Indicators & controls

Two LEDs, two buttons.
The motor tells you what it is doing.

Status LEDs

Green

Flashes slowly as a heartbeat, and quickly to tell you the bootloader is running rather than the application. It also lights up briefly while a packet is being received, so it flickers with traffic on the bus.

Red

Indicates fatal error codes by flashing a certain number of times.

Buttons

Reset

Restarts the microcontroller and returns all state to defaults.

Test

Spins the motor without a computer. A brief press spins one way. Press for more than 0.3 s and release to spin the other way. Hold at least 2 s and release to enter closed-loop mode. Hold more than 15 s and release to run a self-calibration.

The motor spins during calibration and must be able to turn freely — remove any load first.
