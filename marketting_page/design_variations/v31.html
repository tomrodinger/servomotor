Why M17

All-in-one motion control, made simple

Everything a motion axis needs is already inside the motor. No external driver, no timing-critical STEP/DIR signals — just high-level commands over a robust serial bus.

Four devices in one

Motor, driver, motion controller, and encoder in a single compact package — nearly the same size as a NEMA 17 stepper with the same specs.

One bus, unlimited motors

Control any number of motors over a single RS-485 connection. Daisy-chain them and address each one individually from one controller.

High-level commands

Send commands like "Enable MOSFETs" and "Trapezoid move" — no step pulses, no interrupts, no real-time headaches on your controller.

Precision closed loop

Built-in encoder with a PID loop running at 32 kHz keeps every move accurate — and far more power efficient than a conventional stepper.

Protected by design

Integrated over-current, over-voltage, and over-temperature protection, plus comprehensive error handling and LED status indicators.

Works with your platform

Mac, PC, Raspberry Pi, Arduino, or ESP32 — all you need is a low-cost RS485 adapter. Excellent, AI-friendly documentation included.

Get started in minutes

Your first move in six lines

Install the library, plug in the RS485 adapter, and command real motion — in Python or with the Arduino library.

  1. 1

    Install the library

    pip3 install servomotor — Arduino users: search "Servomotor" in the Library Manager.

  2. 2

    Connect the bus

    One low-cost RS485 adapter connects your Mac, PC, Raspberry Pi, Arduino, or ESP32 to the whole daisy-chain.

  3. 3

    Command motion

    High-level commands with real units — degrees and seconds, not step pulses.

first_move.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
