import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s

features

Everything a motion axis needs, in the motor.

No stepper driver board. No timing-critical STEP/DIR pulses. No separate encoder wiring. Send a high-level command over the bus and the motor does the rest.

📄README.md— M17 Series Servomotors

## Why the M17

✓
All-in-one package — motor + driver + motion controller + encoder integrated, no protrusions beyond a normal NEMA 17 stepper.
✓
One bus, any number of motors — daisy-chain over RS-485 and control the whole machine from a single connection point.
✓
High-level commands — "Enable MOSFETs", "Trapezoid move". No timing-critical STEP/DIR signal generation on your controller.
✓
Closed-loop precision — built-in encoder with a PID loop running at 32 kHz. Much more power efficient than a conventional stepper.
✓
Built-in protection — integrated over-current, over-voltage, and over-temperature protection with comprehensive error handling.
✓
Drop-in mechanical fit — standard NEMA 17 mounting, 12–24 V input, up to 560 RPM, same torque-to-weight ratio as an equivalent stepper.
✓
Runs from anything — Raspberry Pi, Arduino, ESP32, Mac, or PC with a low-cost RS485 adapter. Python and Arduino libraries included.
✓
Docs your AI can read — excellent tutorials plus AI-friendly documentation. Let your favorite assistant write the boring parts.

get-started

Wired and spinning before your coffee cools.

Three steps from box to motion. Prefer C++? The Arduino library is in the Library Manager — search "Servomotor".

[1/3] wire

Connect power + RS485

Hook up 12–24 V and the RS485 adapter — the green 3-in-1 adapter PCB handles Mac, PC, Pi, or microcontroller. Daisy-chain additional motors on the same bus.

[2/3] install

Grab the library

Python: pip3 install servomotor
Arduino: Library Manager → Servomotor

[3/3] move

Run the six lines

Reset, enable MOSFETs, and command a trapezoid move in real units — degrees and seconds, not pulses and microseconds.
