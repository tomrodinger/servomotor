Why M17

Everything a motion system needs, already inside.

No separate drivers. No timing-critical STEP/DIR wiring. Send high-level commands like “Enable MOSFETs” and “Trapezoid move”, and let the motor handle the rest.

Four devices in one

Motor, driver, motion controller, and encoder integrated in a body nearly the same size as a NEMA 17 stepper — no protrusions, standard mounting.

One bus, any number of motors

Chain motors over RS-485 and control them all from a single connection point. Just add a low-cost RS485 adapter to almost any platform.

Closed-loop precision

Built-in encoder with a PID loop running at 32 kHz. Self-calibration, trapezoid profiles, LED status, and integrated over-current, over-voltage, and over-temperature protection.

Get started

Spinning in minutes, not weekends.

A few lines of Python is all it takes — one revolution, smoothly profiled, in two seconds. Prefer C++? The Arduino library is in the Library Manager. The documentation is even AI-friendly, so your favorite assistant can do the work.

first_move.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
$ pip3 install servomotor Arduino Library Manager → “Servomotor”
