01 / CAPABILITIES

Built for real work

No STEP/DIR. No external driver. No excuses.
F-01

Fully integrated

Motor, driver, motion controller, and encoder in one package. Wire power and data — done.

F-02

One bus, many motors

Control any number of motors over a single RS-485 bus from one controller. Daisy-chain and go.

F-03

High-level commands

“Enable MOSFETs”, “Trapezoid move” — no timing-critical STEP/DIR signal generation on your host.

F-04

Closed-loop precision

Built-in encoder with a PID loop running at 32 kHz. Position is held, not hoped for.

F-05

Stepper footprint

Nearly the same size as a NEMA 17 stepper with the same specs — no protrusions, standard mounting.

F-06

Efficient by design

Much more power efficient in closed loop than a conventional stepper, with the same torque-to-weight ratio.

F-07

Protected hardware

Integrated over-current, over-voltage, and over-temperature protection with comprehensive error handling.

F-08

Any platform

Mac, PC, Raspberry Pi, Arduino, ESP32 — all it takes is a low-cost RS-485 adapter.

03 / INTEGRATION

Moving in minutes

Python · Arduino · RS-485 @ 230400 baud

Install the library, open the port, move the motor. High-level commands run on the motor itself — your code just says what to do. Multiple operation modes, self-calibration, trapezoid movement profiles, LED status indicators, and comprehensive error handling are all built in.

$ pip3 install servomotor

Prefer C++? The “Servomotor” Arduino library is available in the Library Manager.

  • Mac / PCUSB → RS-485 adapter
  • Raspberry PiUSB → RS-485 adapter
  • ArduinoLibrary Manager: “Servomotor”
  • ESP32Low-cost RS-485 adapter

The documentation is written to be AI-friendly — hand it to your favorite AI and let it do the work.

Read the docs
first_move.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
