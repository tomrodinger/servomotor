The M17 Series

Motor, driver, controller and encoder — engineered as one

Each M17 servomotor integrates a motor, motor driver, motion controller and encoder in a single compact package that is nearly the same size as a NEMA 17 stepper with the same specs — no protrusions, no separate drive cabinet.

  • Daisy-chain any number of motors on one RS-485 bus, from one connection point
  • High-level commands like "Enable MOSFETs" and "Trapezoid move" — no timing-critical STEP/DIR signals
  • Standard NEMA 17 mounting dimensions, 12–24 V operation
  • Integrated over-current, over-voltage and over-temperature protection

Closed-Loop Control

Precision that steppers can't hold

A built-in encoder and a PID loop running at 32 kHz keep every move on target. Closed-loop operation is far more power efficient than a conventional stepper, while delivering the same torque-to-weight ratio.

  • Self-calibration and multiple operation modes
  • Trapezoid movement profiles with comprehensive error handling
  • LED status indicators for at-a-glance diagnostics

Get Started

One revolution in six lines of Python

Control the M17 from a Mac, PC, Raspberry Pi, Arduino or ESP32 — all it takes is a low-cost RS485 adapter. Install the library, open the port, move the motor. An Arduino library is available in the Library Manager under "Servomotor".

$ pip3 install servomotor
Documentation →
move.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
