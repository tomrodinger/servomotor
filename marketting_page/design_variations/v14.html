Hi there, welcome to Gearotons

Affordable and simple all-in-one motion control — the M17 Series Servomotors.

Plug a motor into a low-cost RS485 adapter, type pip3 install servomotor, and you're moving in minutes — from a Mac, PC, Raspberry Pi, Arduino, or ESP32. High-level commands, excellent tutorials, and AI-friendly docs mean no timing-critical STEP/DIR wrangling.

Motor, driver, motion controller, and encoder in one NEMA 17-size package. Daisy-chain any number of axes on a single RS-485 bus with closed-loop control at 32 kHz, integrated over-current, over-voltage, and over-temperature protection, and a robust documented protocol.

Moving in six lines of Python

Install the library, open the port, and send a trapezoid move. That's the whole quick start — and if you prefer Arduino, the "Servomotor" library is in the Library Manager.

PYTHON pip3 install servomotor ARDUINO Library Manager → "Servomotor"
Read the documentation
quick_start.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
