Why M17

Everything a motion axis needs, built in

No external driver. No motion controller board. No encoder wiring. No timing-critical STEP/DIR signals. Just power, two RS-485 wires, and high-level commands.

Truly all-in-one

Motor, driver, motion controller, and encoder integrated in one package — nearly the same size as an equivalent NEMA 17 stepper, with no protrusions.

One bus, unlimited motors

Control any number of motors over a single RS-485 daisy chain from one controller — clean wiring even on large multi-axis machines.

High-level commands

Send commands like "Enable MOSFETs" and "Trapezoid move" — the motor handles motion profiles onboard. No pulse trains to generate.

Precise closed-loop control

Built-in encoder with a PID loop running at 32 kHz delivers high-precision positioning — and far better power efficiency than a conventional stepper.

Protected by design

Integrated over-current, over-voltage, and over-temperature protection with comprehensive error handling, self-calibration, and LED status indicators.

Works with your platform

Mac, PC, Raspberry Pi, Arduino, ESP32 — all you need is a low-cost RS485 adapter. Backed by excellent, AI-friendly documentation and tutorials.

Three Models

Get Started in Minutes

From unboxing to motion in a few lines of Python

Plug in power and the RS485 adapter, install the library, and your motor is turning. The same high-level commands are available from Arduino, too.

  • Python: pip3 install servomotor
  • Arduino: search "Servomotor" in the Library Manager
  • Any host: Mac, PC, Raspberry Pi, Arduino, or ESP32 with a low-cost RS485 adapter
Read the Documentation
one_revolution.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
That's the whole program. pip3 install servomotor
