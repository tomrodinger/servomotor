Four instruments,
one enclosure.

The M17 Series integrates a motor, motor driver, motion controller and encoder in a single package nearly the same size as the NEMA 17 stepper it replaces — with no protrusions and standard mounting dimensions.

  • Closed-loop control: built-in encoder, PID loop at 32 kHz
  • Far more power efficient than a conventional stepper
  • Over-current, over-voltage and over-temperature protection
  • Wide 12–24 V operating range, up to 560 RPM

02

Any number of motors.
One connection point.

An RS-485 interface lets you daisy-chain motor after motor along a single robust bus and command them all from one port — from a Mac, PC, Raspberry Pi, Arduino or ESP32, with nothing more than a low-cost RS485 adapter.

High-level commands such as Enable MOSFETs and Trapezoid move replace timing-critical STEP/DIR signals entirely, with comprehensive error handling built into the protocol.

04

A full revolution,
in plain Python.

Open the port, reset, enable, move. No pulse trains, no timing loops, no motion mathematics — the controller inside the motor handles trapezoid profiles, calibration and closed-loop correction for you.

An Arduino library is available in the Library Manager (“Servomotor”), and the documentation is written to be AI-friendly — let your favorite assistant do the work.

Documentation →
first_move.pyPython
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
$ pip3 install servomotor
