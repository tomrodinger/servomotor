Welcome to the world of precise motion

Powering machines. Empowering makers.

Three models — M17-60, M17-48, M17-40 — with flexible torque options and identical control characteristics. Standard NEMA 17 mounting, 12–24 V, and a robust protocol that speaks to Mac, PC, Raspberry Pi, Arduino, and ESP32.

Why M17

Everything a motion system needs, already inside.

Four devices in one

Motor + driver + motion controller + encoder integrated in a single package — nearly the same size as a NEMA 17 stepper with the same specs, no protrusions.

One bus, endless motors

Daisy-chain any number of motors over a single RS-485 connection and control them all from one point.

High-level commands

Say "Enable MOSFETs" or "Trapezoid move" — no timing-critical STEP/DIR signals, ever.

Closed loop at 32 kHz

Built-in encoder plus a PID loop running at 32 kHz delivers high-precision closed-loop control — and much better power efficiency than a conventional stepper.

Protected by design

Integrated over-current, over-voltage, and over-temperature protection with comprehensive error handling, self-calibration, and LED status indicators.

Any platform, AI-friendly docs

Works with Raspberry Pi, Arduino, ESP32, Mac, and PC. Excellent tutorials and AI-friendly documentation — let your favorite AI do the work.

Get started

From unboxing to full rotation in minutes.

No motion-control PhD required. Install the Python library — or grab "Servomotor" from the Arduino Library Manager — plug in a low-cost RS485 adapter, and send your first trapezoid move.

$ pip3 install servomotor
Documentation
first_move.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
