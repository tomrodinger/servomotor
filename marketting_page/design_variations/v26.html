Why M17

Everything a motion axis needs.
Nothing it doesn't.

No separate drivers, no timing-critical STEP/DIR wiring, no external encoders. Send a high-level command like "Trapezoid move" and the motor handles the rest.

01

Fully integrated

Motor + driver + motion controller + encoder in a single package, nearly the same size as an equivalent NEMA 17 stepper — with no protrusions.

02

One bus, unlimited axes

Control any number of motors over one RS-485 daisy chain from a single connection point on your controller.

03

32 kHz closed loop

High-precision closed-loop control with a built-in encoder and a PID loop running at 32 kHz — far more power efficient than a conventional stepper.

04

High-level commands

Commands like "Enable MOSFETs" and "Trapezoid move" replace timing-critical step pulses. Multiple operation modes, self-calibration, and comprehensive error handling built in.

05

Built-in protection

Integrated over-current, over-voltage, and over-temperature protection, plus LED status indicators and a robust communication protocol. 12–24V input.

06

Any platform

Works with Mac, PC, Raspberry Pi, Arduino, and ESP32 — all you need is a low-cost RS485 adapter. Excellent, AI-friendly documentation.

Quick Start

Six lines to first motion

Open a port, reset, enable, move. That's the whole program — no pulse trains, no interrupt timing, no driver tuning.

  • pip3 install servomotor and you're ready on Mac, PC, or Raspberry Pi.
  • Arduino library available in the Library Manager ("Servomotor") for Arduino and ESP32.
  • Trapezoid movement profiles, unit-aware positions and times, comprehensive error handling.
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
$ pip3 install servomotor
