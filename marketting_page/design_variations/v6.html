Introduction

All-in-one motion control

Most motion systems are an assembly of compromises: a motor here, a driver there, a controller somewhere else, and a nest of timing-critical wiring holding it all together. The M17 Series takes a different view. Each unit integrates the motor, the motor driver, the motion controller, and the encoder in a single compact package — nearly the same size as a NEMA 17 stepper of equivalent specification, with no protrusions.

Control is equally uncluttered. A single RS‑485 connection carries high-level commands — Enable MOSFETs, Trapezoid move — to any number of motors daisy-chained on the bus. No STEP/DIR pulse trains, no dedicated wiring per axis, no real-time constraints on your host. A Mac, a PC, a Raspberry Pi, an Arduino, or an ESP32 with a low-cost RS‑485 adapter is all the controller you need.

Inside, a built-in encoder and a PID loop deliver high-precision closed-loop control — considerably more power-efficient than a conventional stepper running open loop — with self-calibration, trapezoid movement profiles, multiple operation modes, LED status indication, and integrated over-current, over-voltage, and over-temperature protection.

The Engineering

What makes it different

The point of integration is not compactness for its own sake. It is what becomes possible when the whole control chain lives inside the motor.

i.

One bus, any number of axes

Every motor on the RS‑485 bus is addressable from a single connection point. Add an axis by adding a cable — the host-side wiring never grows.

ii.

High-level commands, no pulse trains

Commands like “Enable MOSFETs” and “Trapezoid move” replace timing-critical STEP/DIR signals. Your controller sends intent; the motor handles the microseconds.

iii.

True closed-loop precision

A built-in encoder feeds a PID loop running at 32 kHz — and closed-loop operation is much more power-efficient than a conventional stepper.

iv.

A stepper's body, without the bulk

Standard NEMA 17 mounting, the same torque-to-weight ratio as an equivalent stepper, and nearly the same overall size — with no protrusions to design around.

v.

Protection, integrated

Over-current, over-voltage, and over-temperature protection are built in, alongside comprehensive error handling and LED status indicators.

vi.

Documentation worth reading

Excellent tutorials and reference material — written to be AI-friendly, so your favorite assistant can do the integration work with you.

Getting Started

Seven lines to first motion

From a sealed box to a turning shaft in minutes, from any platform you already own — Mac, PC, Raspberry Pi, Arduino, or ESP32.

Install the Python library, open the serial port, and issue high-level commands. One full revolution, executed as a smooth trapezoid profile over two seconds, is a single line of code. An Arduino library is available too — search for “Servomotor” in the Library Manager.

Python

pip3 install servomotor

Arduino

Library Manager → "Servomotor"
Read the documentation
first_move.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s

One adapter, then daisy-chain

The 3‑in‑1 RS‑485 adapter connects your computer or microcontroller to the bus. From there, motors chain from one to the next over a robust protocol at 12–24 V supply — no per-axis wiring back to the host.

Open by Design

Hardware · firmware · libraries

Gearotons is an innovative young startup making precision motion control accessible to everyone — makers, educators, and engineers. Founded in Shenzhen in 2022 by a Canadian entrepreneur, the company builds in the open: the firmware, the control libraries, and the hardware schematics are all published on GitHub.

Open source means you can read exactly what runs inside your motor, extend it, fix it, and trust it — for a classroom, a laboratory, or a production line.
