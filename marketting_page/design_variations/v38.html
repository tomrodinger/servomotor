Why M17

All-in-one motion control, made human

Four components become one. High-level commands replace timing-critical signals. And any number of motors daisy-chain on a single RS-485 bus, controlled from whatever computer you already have.

Four devices in one

Motor, driver, motion controller, and encoder integrated in a single package — nearly the same size as a NEMA 17 stepper with the same specs, no protrusions.

One bus, many motors

Daisy-chain any number of motors over RS-485 and control them all from a single connection point — Mac, PC, Raspberry Pi, Arduino, or ESP32.

High-level commands

Say "Trapezoid move," not step-step-step. No timing-critical STEP/DIR signals — just clear commands like "Enable MOSFETs" and smooth motion profiles.

Closed-loop precision

A built-in encoder and a PID loop running at 32 kHz keep position honest — and make the M17 far more power efficient than a conventional stepper.

Protection built in

Integrated over-current, over-voltage, and over-temperature protection, plus self-calibration, LED status indicators, and comprehensive error handling.

Documentation people enjoy

Excellent tutorials and AI-friendly docs — hand them to your favorite assistant and let it write the first draft of your motion code.

Get started

Your first revolution in five lines

Plug in a low-cost RS485 adapter, install the library, and you're moving. An Arduino library is in the Library Manager too — search "Servomotor".

  1. Connect

    Wire the motor to 12–24 V and to your computer through an RS485 adapter. Chain more motors on the same bus whenever you like.

  2. Install

    One command: pip3 install servomotor. Works on Mac, PC, Raspberry Pi — and there's a matching library for Arduino and ESP32.

  3. Move

    Reset, enable, and send a trapezoid move in units you actually think in — degrees and seconds.

first_move.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
