Innovating in motion control

A conventional stepper setup asks you to assemble four products and hope they cooperate. The M17 Series asks you to plug in one cable. Here is how a young company from Shenzhen is rethinking the way machines move.

Four devices. One quiet package.

Motor, driver, motion controller, and encoder live together behind one connector — in nearly the same size as a NEMA 17 stepper with the same specs, and with the same torque-to-weight ratio.

Read more →

One bus, any number of motors.

A low-cost RS-485 adapter connects your Mac, PC, Raspberry Pi, Arduino, or ESP32 to a daisy-chain of motors — every axis addressed and commanded from a single connection point.

Read more →

Closed loop, open efficiency.

The built-in encoder and a 32 kHz PID loop hold position precisely while drawing far less power than a conventional stepper — with protection circuits watching current, voltage, and temperature.

A full revolution, in six lines.

Install the Python library, open the serial port, and command motion in the units you think in — degrees and seconds, not pulses and microsteps. An Arduino library is available in the Library Manager (“Servomotor”).

pip3 install servomotor

Explore the documentation →

import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
