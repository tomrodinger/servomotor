Why M17

Everything a stepper isn't.

Same NEMA 17 footprint. Same torque-to-weight ratio. None of the timing-critical wiring headaches.

01

All-in-one package

Motor, driver, motion controller, and encoder integrated in a body nearly the same size as a NEMA 17 stepper with the same specs — no protrusions.

02

One bus, endless motors

Control any number of motors over a single RS-485 connection. One cable in, daisy-chain the rest.

03

High-level commands

Say "Enable MOSFETs" or "Trapezoid move" — no timing-critical STEP/DIR signals to generate, ever.

04

True closed loop

Built-in encoder with a PID loop running at 32 kHz for high-precision positioning — and much better power efficiency than a conventional stepper.

05

Protected by design

Integrated over-current, over-voltage, and over-temperature protection with comprehensive error handling and LED status indicators.

06

AI-friendly docs

Excellent documentation and tutorials, written so your favorite AI can do the heavy lifting for you.

Get started

Spinning in six lines.

  • Works from Mac, PC, Raspberry Pi, Arduino, or ESP32
  • Only a low-cost RS485 adapter needed
  • Self-calibration and multiple operation modes built in
  • Trapezoid movement profiles out of the box
pip3 install servomotor

Read the Docs
spin.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
