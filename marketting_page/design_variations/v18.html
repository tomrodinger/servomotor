From unboxing to motion in a few lines

No motion-control card, no pulse trains, no tuning marathon. Install the library, open the port, and send high-level commands like enable_mosfets() and trapezoid_move().

Works from Mac, PC, Raspberry Pi, Arduino, or ESP32 — all you need is a low-cost RS485 adapter.

pip3 install servomotor  ·  Arduino: search "Servomotor" in the Library Manager

import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s

About Us

Gearotons is an innovative startup making precision motion control accessible to everyone — makers, educators, and engineers. Founded in Shenzhen in 2022 by a Canadian entrepreneur, we build all-in-one servomotors that remove the cost and complexity barriers of traditional motion systems.
