Developers

One Revolution in Six Lines of Python.

Control from Mac, PC, Raspberry Pi, Arduino, or ESP32 — all you need is a low-cost RS-485 adapter. Excellent, AI-friendly documentation means your favorite AI can do the work too.

  1. Install the library

    Run pip3 install servomotor — or grab “Servomotor” from the Arduino Library Manager.

  2. Wire up RS-485

    Connect the adapter, daisy-chain as many motors as you like, and power them with anything from 12 to 24V.

  3. Send high-level commands

    Reset, enable the MOSFETs, and issue a trapezoid move in real-world units — degrees and seconds, not pulses.

hello_motion.pyPython 3
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s

Prefer C++? The same commands are available in the Arduino library — search “Servomotor” in the Library Manager.
