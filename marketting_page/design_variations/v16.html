SEARCH

Engineered as one system

Four components — motor, driver, motion controller, encoder — integrated into a package nearly the same size as a standard NEMA 17 stepper, with no protrusions.

Everything integrated

High-level commands like “Enable MOSFETs” and “Trapezoid move” replace timing-critical STEP/DIR signals. A built-in encoder and a PID loop running at 32 kHz deliver high-precision closed-loop control with far better power efficiency than a conventional stepper.

LEARN MORE>

One bus, any number of motors

The RS-485 interface lets you daisy-chain any number of motors and control them all from a single connection point — with a robust protocol, CRC error checking, and integrated over-current, over-voltage, and over-temperature protection.

LEARN MORE>

Control from any platform

Mac, PC, Raspberry Pi, Arduino, ESP32 — all you need is a low-cost RS485 adapter. Wide 12–24 V operating range, standard NEMA 17 mounting, up to 560 RPM, and self-calibration out of the box.

From unboxing to motion in minutes

Install the Python library with pip3 install servomotor, open a serial port, and command your first move. No motion-controller boards, no step pulses, no interrupts to tune.

Prefer C++? The Arduino library is available in the Library Manager — search for Servomotor. Firmware, libraries, and schematics are open source on GitHub.

READ THE DOCUMENTATION>
first_move.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
