All-in-one integration

Motor + driver + motion controller + encoder in a single package barely bigger than a standard NEMA 17 stepper — no protrusions.

One bus, any number of motors

Control an entire machine over a single RS‑485 daisy chain from one connection point — add axes without adding controllers.

High-level commands

Say “Enable MOSFETs” or “Trapezoid move” instead of generating timing-critical STEP/DIR pulses. Your code stays simple.

32 kHz closed-loop control

Built-in encoder and a PID loop running at 32,000 updates per second deliver high-precision positioning and far better power efficiency than an open-loop stepper.

Protected by design

Integrated over-current, over-voltage, and over-temperature protection with comprehensive error handling and LED status indicators.

Works with your platform

Mac, PC, Raspberry Pi, Arduino, or ESP32 — all it takes is a low-cost RS‑485 adapter. Python and Arduino libraries included.

Three sizes, one control experience

M17-60, M17-48, and M17-40 share the same footprint, protocol, and control characteristics — pick the torque and budget that fit.

Standard NEMA 17 mounting, zero surprises

Every M17 uses the standard 42.2 × 42.2 mm NEMA 17 footprint and runs from 12–24V, so it drops into existing designs. Same torque-to-weight ratio as an equivalent stepper — with self-calibration, trapezoid motion profiles, and multiple operation modes on board.

From unboxing to motion in minutes

No motion-control background required. Install the library, open the port, and send your first move.

  • Python: pip3 install servomotor
  • Arduino: search “Servomotor” in the Library Manager
  • Excellent, AI-friendly documentation — let your favorite AI do the work
Documentation
first_move.py
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
$ pip3 install servomotor
