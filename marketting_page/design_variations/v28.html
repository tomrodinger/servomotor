Get Started

From Unboxing to Motion in Minutes

Open a serial port, reset, enable, move. High-level commands and sensible units — seconds and degrees — mean your first revolution is a few lines away.

pip3 install servomotor

Prefer Arduino? Find “Servomotor” in the Library Manager.

Read the Docs
first_move.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
