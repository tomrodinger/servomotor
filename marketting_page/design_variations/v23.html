M17 Series Servomotors.
All-in-one motion control.

Motor, driver, motion controller, and encoder — integrated in one compact NEMA 17 package. Daisy-chain any number of motors on a single RS‑485 bus and command them with high-level moves from a Mac, PC, Raspberry Pi, Arduino, or ESP32.

Read the Docs Explore the three models →
Why M17

Everything a motion axis needs, nothing it doesn’t.

No step/dir timing, no external drivers, no encoder wiring. One cable in, precise closed-loop motion out.

01

Fully integrated

Motor + driver + motion controller + encoder in a single package — nearly the same size as an equivalent NEMA 17 stepper, with no protrusions.

02

One bus, many motors

Control any number of motors over one RS‑485 connection with a robust protocol — from one controller and one port.

03

High-level commands

Send commands like “Enable MOSFETs” and “Trapezoid move” — no timing-critical STEP/DIR signal generation required.

04

Closed-loop precision

Built-in encoder with a PID loop running at 32 kHz — and much better power efficiency than a conventional stepper.

05

Protected by design

Integrated over-current, over-voltage, and over-temperature protection, plus self-calibration, LED status indicators, and comprehensive error handling.

06

Any platform

Works with Raspberry Pi, Arduino, ESP32, Mac, and PC using only a low-cost RS‑485 adapter. 12–24V input, standard NEMA 17 mounting.

Get Started

From unboxing to motion in a few lines of Python.

Open a serial port, reset, enable, move. That’s the whole program. Arduino is equally simple — the library is in the Library Manager under “Servomotor”.

Excellent documentation and tutorials → AI-friendly docs — let your favorite AI do the work → Firmware, libraries & schematics on GitHub →
Read the Docs
first_move.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
$ pip3 install servomotor
