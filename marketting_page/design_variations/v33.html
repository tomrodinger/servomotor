Everything a motion axis needs, in one body

No external driver. No motion-controller board. No separate encoder. Each M17 is a complete closed-loop axis that is nearly the same size as the NEMA 17 stepper it replaces.

From unboxing to motion in minutes

Control from Mac, PC, Raspberry Pi, Arduino, or ESP32 — all you need is a low-cost RS-485 adapter. One revolution in six lines of Python.

first_move.py 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
pip3 install servomotor Arduino: Library Manager → "Servomotor"
