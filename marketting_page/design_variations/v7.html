Sheet 2 — Design Notes

Everything integrated.
Nothing improvised.

Four components in one housing, no protrusions — nearly the same size as a NEMA 17 stepper with the same specs, and the same torque-to-weight ratio.

Note 01

Four-in-one package

Motor, driver, motion controller, and encoder in a single compact unit. Bolt it on, wire two data lines, done.

Note 02

One bus, unlimited axes

Control any number of motors over one RS-485 bus from a single controller — Mac, PC, Raspberry Pi, Arduino, or ESP32.

Note 03

High-level commands

Send "Enable MOSFETs" or "Trapezoid move" over a robust protocol. No timing-critical STEP/DIR pulse trains to generate.

Note 04

Closed-loop precision

Built-in encoder with a PID loop running at 32 kHz — and much better power efficiency than a conventional stepper.

Note 05

Protected by design

Integrated over-current, over-voltage, and over-temperature protection, plus self-calibration, LED status indicators, and comprehensive error handling.

Note 06

AI-friendly documentation

Excellent docs and tutorials, structured so your favorite AI can read them and write your motion code for you.

Sheet 4 — Assembly & Commissioning

From box to motion in minutes.

  1. 01
    Connect

    Wire the motor to any Mac, PC, Raspberry Pi, Arduino, or ESP32 through a low-cost RS-485 adapter. Chain as many motors as you need.

  2. 02
    Install

    One command: pip3 install servomotor. On Arduino, grab "Servomotor" from the Library Manager.

  3. 03
    Move

    Send high-level commands — trapezoid moves, multiple operation modes, closed-loop control — in a few readable lines of code.

first_move.py Python 3 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s

pip3 install servomotor · Arduino library "Servomotor" in the Library Manager
