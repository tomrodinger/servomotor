Key Features

Sect. 1 / 6
1.1

Four devices in one package

Motor + driver + motion controller + encoder, integrated. No external driver boards, no wiring rat's nest — nearly the same size as an equivalent NEMA 17 stepper, with no protrusions.

1.2

One bus, any number of motors

Control an entire machine over a single RS-485 connection. Each motor is addressable; daisy-chain as many as your application needs.

1.3

High-level commands

Send "Enable MOSFETs" or "Trapezoid move" — the motor handles the profile. No timing-critical STEP/DIR signals from your host.

1.4

Closed-loop precision

Built-in encoder with a PID loop running at 32 kHz. Much more power efficient in closed loop than a conventional stepper, with the same torque-to-weight ratio.

1.5

Integrated protection

Over-current, over-voltage, and over-temperature protection built in, with comprehensive error handling, self-calibration, and LED status indicators.

1.6

Any platform, well documented

Works with Mac, PC, Raspberry Pi, Arduino, and ESP32 via a low-cost RS-485 adapter. Excellent, AI-friendly documentation and tutorials — let your favorite AI do the work.

System Overview

Wiring & identification

One cable. One bus. Whole machine.

Connect your host — Mac, PC, Raspberry Pi, Arduino, or ESP32 — through a low-cost RS-485 adapter, then daisy-chain from motor to motor. A robust protocol with error handling carries commands and status over the bus.

Fig. 2 — Typical connection topology

Engineered to be serviced.

Every motor carries its specifications and QR codes printed on the rear label, with Reset and Test buttons accessible on the housing. Self-calibration and LED status indicators keep commissioning simple.

Fig. 3 — Rear label, Reset / Test buttons

Getting Started

Python · Arduino

One revolution in seven lines.

Install the library, open the port, and command a trapezoid move in real units — degrees and seconds. Multiple operation modes, closed-loop control, and comprehensive error handling are all one method call away.

Python pip3 install servomotor
Arduino Library Manager → "Servomotor"
example.py python 3 
import servomotor
from servomotor import M3

servomotor.open_serial_port()
motor = M3("X", time_unit="seconds",
                position_unit="degrees")
motor.system_reset()
motor.enable_mosfets()
motor.trapezoid_move(360, 2)  # one revolution in 2 s
