Checks and tools

Cycler self-test Loads all 20 in iframes and asserts the spec: the hook exists, 15 slogans, seek works, hero height never varies across slogans, no horizontal overflow.
Run these from marketting_page/:
python3 -m http.server 8912 — serve everything (already running)
premium_minimal_variations/_audit.sh — verify the four-motor specs on all 20 pages
python3 premium_minimal_variations/_reap.py — kill orphaned headless Chrome (never matches your real browser)
python3 slogan_lab/make_gifs.py — re-export every effect to GIF
python3 slogan_lab/build_manifest.py — after adding an effect file
